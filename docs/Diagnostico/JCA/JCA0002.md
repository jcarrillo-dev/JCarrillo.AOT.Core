# Diagnóstico JCA0002: Materialización a colecciones estándar con allocations

## 1. Metadatos del Diagnóstico
- **Gravedad**: Warning
- **Categoría**: Performance
- **Objetivo**: Métodos `ToArrayStandard` y `ToListStandard` (motor Eager)

## 2. Descripción
Bajo las reglas de optimización de cero asignaciones (zero-allocation), los materializadores estándar asignan memoria en el heap administrado debido a que retornan arrays tradicionales (`T[]`) o colecciones de lista (`List<T>`). Estas asignaciones son gestionadas por el recolector de basura (GC), introduciendo latencia en la ruta caliente de ejecución.

En la escala de $N = 1000$ elementos bajo .NET 10.0 JIT, `ToArrayStandard` asigna 4024 B **(medido)** en heap, mientras que `ToListStandard` asigna 4056 B **(medido)** en heap.

## 3. Mitigación y Remediación
Se recomienda sustituir las llamadas a los materializadores estándar por sus variantes optimizadas basadas en pools: `ToArray()` y `ToList()`. Estas variantes retornan estructuras `PooledArray<T>` y `PooledList<T>`, las cuales reutilizan buffers del pool de memoria (`ArrayPool<T>.Shared`), reduciendo las asignaciones en heap a 0 B **(medido)**. 

*Nota: Al utilizar colecciones de tipo pooled, el desarrollador debe asegurar la devolución de la memoria mediante el uso de bloques `using` o llamadas explícitas a `Dispose()`*.

## 4. Ejemplos de Código

### Código no recomendado (Asignación en Heap)
```csharp
using var query = data.ToValueQuery().Where(0, ref filtro);
// Genera una asignación en heap del array administrado devuelto
var array = query.ToArrayStandard(); 
```

### Código recomendado (Cero Asignaciones)
```csharp
using var query = data.ToValueQuery().Where(0, ref filtro);
// Utiliza memoria alquilada de ArrayPool y opera con 0 B de asignación
using var array = query.ToArray(); 
```

## 5. Supresión de la Advertencia
Si la asignación en heap en esta sección del código es aceptable y no forma parte de una ruta caliente de ejecución, la advertencia se puede desactivar mediante directivas de preprocesamiento:

```csharp
#pragma warning disable JCA0002
var array = query.ToArrayStandard();
#pragma warning restore JCA0002
```

O de forma global en el archivo de configuración del proyecto (`.csproj`):
```xml
<NoWarn>$(NoWarn);JCA0002</NoWarn>
```
